# Prodesk IT Landing Page

I made this responsive landing page for the Prodesk IT internship project.

## Live Website

[Open Prodesk IT website](https://prodesk-sprint-1-seven.vercel.app/)

## Technologies Used

- HTML
- CSS
- JavaScript

## Main Features

- Responsive layout for desktop, tablet and mobile
- Navbar with mobile hamburger menu
- Hero section with Get Started button
- Three service cards using CSS Grid
- Dark and light theme button
- Smooth scrolling for navigation links
- Hover effects on buttons and service cards
- Footer with LinkedIn, website and WhatsApp links

## Project Files

- `index.html` - page structure
- `style.css` - colors, layout and responsive design
- `script.js` - menu, theme button, scrolling and form validation
- `Prompts.md` - prompts used during development

## AI Assistance

I used GitHub Copilot as an assistant for checking bugs, improving CSS, understanding JavaScript and reviewing the website. I selected the page colors, layout and main design decisions myself.
